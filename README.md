# Predicto11 - Premium Sports Betting Platform

Predicto11 is a high-performance, real-time sports betting application featuring a premium glassmorphic dark theme, multi-currency support, a simulated crypto deposit network, live match event trackers, and an interactive backoffice administrator control panel.

## Features

- **Rebranded Dark UI:** Glassmorphism dashboard styled in charcoal, slate, and glowing emerald accents.
- **User Authentication:** Supports registrations and sessions for User IDs, emails, and mobile numbers.
- **Crypto-Fiat Exchange Converter:** Select INR (₹), USD ($), or EUR (€) to convert USDT, BTC, and ETH holdings instantly.
- **2D Match Visualization Tracker:** Render live football fields, tennis courts, and cricket pitches with running actions.
- **Live Odds Ticker Simulator:** Watch decimal odds fluctuate every 5 seconds with custom flashing animations.
- **Admin Control Panel:** Override match scores, advance clock timings, log event commentary, and monitor user bet ledgers.
- **Live Chat Bot:** Get immediate customer support details using keywords like `deposit` or `fiat`.

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the Vite development server:
   ```bash
   npm run dev
   ```
